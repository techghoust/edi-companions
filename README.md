# EDI DEVELOPER JOURNAL COMPANION🐙

a lightweight local bridge between VS Code, PyCharm, WebStorm, CLion and EDI Developer Journal

current version: `0.3.0`

---

# THE IDEA

use EDI without leaving the editor. open the current project in the journal or turn the code you are looking at into a note, decision, experiment or research item

the extension sends context to the desktop application through a local connection. EDI remains responsible for project matching, storage and the journal interface

---

## HOW IT WORKS

```text
[ VS Code / JetBrains IDE ]
             ↓
      EDI Companion command
             ↓
     local Integration Protocol v1
             ↓
   [ EDI Developer Journal ]
```

the extension can include:

- the local workspace and repository path;
- the current file and programming language;
- the cursor or selected range;
- explicitly selected text;
- the current Git branch, commit and remote

an empty selection never sends the full file

---

## COMMANDS

- `EDI: Open Project in EDI`;
- `EDI: Add Note`;
- `EDI: Add Decision`;
- `EDI: Add Experiment`;
- `EDI: Add Research`

the four Add commands are also available from the editor context menu:

```text
right click -> Send to EDI -> Add Note / Decision / Experiment / Research
```

each Add command asks for a title and an optional short comment. EDI stores the new item together with its editor context. repeated delivery of the same request does not create a duplicate

## INSTALLATION

requirements:

- desktop VS Code `1.96.0` or newer, or PyCharm, WebStorm or CLion `2025.2` or newer;
- EDI Developer Journal with Integration Protocol v1;
- a local Windows, Linux or macOS workspace

install the VS Code extension:

1. open the [latest GitHub release](https://github.com/techghoust/edi-vscode/releases/latest) and download `edi-vscode-0.3.0.vsix`;
2. open the Command Palette in VS Code;
3. run `Extensions: Install from VSIX...`;
4. choose the VSIX file;
5. reload the VS Code window

if EDI is not found automatically, run any EDI command and choose **Select EDI Executable**. the selected path is saved in the global `edi.executablePath` setting

### JetBrains IDEs

download the JetBrains plugin zip from the latest GitHub release. in PyCharm, WebStorm or CLion, open Settings -> Plugins -> gear menu -> Install Plugin from Disk, select the zip, then restart the IDE

the shared JetBrains plugin adds `Tools → EDI` commands and a `Send to EDI` editor menu. use `Configure EDI Executable` to select a portable executable or macOS app bundle

the complete setup and usage instructions are in `USER_GUIDE.md`

## PRIVACY

- all communication stays on `127.0.0.1`;
- no telemetry or analytics;
- no cloud requests;
- no repository scan;
- no direct access to the EDI database;
- no source text is sent until the user runs a command;
- Git commands are read-only

the local API uses a temporary access token generated by EDI. the token is not stored in the workspace or extension settings

---

## SETTINGS

- `edi.executablePath` — explicit path to the EDI executable;
- `edi.autoDetect` — look for EDI in standard installation folders;
- `edi.showSuccessNotifications` — show confirmation after a successful command

---

## LIMITATIONS

the companions support local desktop workspaces. Remote SSH, WSL, Dev Containers, Codespaces, virtual workspaces and vscode.dev are not supported because their files may exist on another machine
