# Changelog

## 0.3.0

- update the VS Code companion for EDI Developer Journal 0.4 without changing Integration Protocol v1;
- use the correct macOS Application Support directory for runtime discovery;
- detect and launch the macOS EDI app bundle;
- add a shared JetBrains plugin for PyCharm, WebStorm and CLion;
- support portable EDI executable and app bundle selection;
- send project, Git and explicitly selected editor context through the local API

## 0.2.0

- add Note, Decision, Experiment and Research commands;
- add the `Send to EDI` editor context submenu;
- preserve file, language, zero-based selection range, branch and commit as structured source context;
- prevent duplicate entries when a request is retried

## 0.1.0

- add the local EDI Integration Protocol v1 client;
- add `EDI: Open Project in EDI`;
- add safe local workspace and read-only Git context detection
